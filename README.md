# Gerenciador de Tarefas

Projeto simples em **Python** para gerenciar tarefas pelo terminal. Feito para praticar lógica de programação, funções, manipulação de arquivos e organização de código.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas (com marcação de concluídas)
- Concluir tarefas
- Remover tarefas
- Salvamento automático em arquivo JSON (as tarefas continuam ao fechar o programa)

## Como executar

Pré-requisito: [Python 3](https://www.python.org/downloads/) instalado.

```bash
git clone https://github.com/Pandamaximus28409/gerenciador-de-tarefas.git
cd gerenciador-de-tarefas
python main.py
```

## Tecnologias

- Python 3 (biblioteca padrão: `json` e `pathlib`)
